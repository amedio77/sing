# 12. 무대 멘트 — 설계

> 노래 모임 발표(공개 장소, 처음 보는 관객 다수, **앵콜 없음**)에서 네 곡 앞뒤로 할 멘트.
> 원문은 `karaoke/lyrics-source.md` 의 `[멘트]` · `[마무리]` 단락에 있다. 고친 뒤 `build_songs.py` 를 다시 돌린다.

---

## 1. 전체 설계 (v3)

v1(네 장면 서사)과 v2(억지로 잇는 말)는 꾸민 느낌이 강해서 버렸다. v3는 곡마다 **곡 소개 → 가사 속 장면 하나 → 그 장면 뒤에 숨은 마음 한 줄**로 간다.
곡 순서(사랑 → 이별 → 미련 → 감사)가 흐름을 만들고, 담배 농담 하나만 오프닝에서 깔고 마무리에서 회수한다.

| 순서 | 가사 속 장면 | 숨은 마음 한 줄 |
|---|---|---|
| 오프닝 | — | 무대 때문에 담배를 끊었는데, 지금이 담배 생각이 제일 간절한 순간 → 그만큼 떨린다 |
| 사랑하기 때문에 | 분홍빛 추억들이 푸르게 바래졌다 | 여러분의 바랜 추억에 다시 분홍빛이 돌기를 |
| 암연 | 일어서려 하자 잡은 손을 놓지 않음 | (v4) 노래방에서 남이 예약한 곡을 부르다 내 노래가 됨 → 나도 그날 마이크를 못 놓았다 |
| 앵콜요청금지 | 안 돼요, 끝나버린 노래를 다시 부를 순 없어요 | 덤덤하게 말하기까지 얼마나 실망하고 아파했을까 |
| 다행이다 | 고된 살아남기가 행여 무의미한 일이 아니라는 게 | '다행이다'는 두려웠던 사람이 하는 말 |
| 마무리 | — | 앵콜 없이 인사 + 긴장이 풀리니 담배 생각도 덜하다 |

## 2. 멘트 원칙
- 곡당 약 30초. 과장하지 않고, 감정을 늘어놓지 않고 한 문장으로 짚는다.
- 공개 장소라 존댓말로 하고, 농담은 누구나 알아듣는 것만 쓴다.
- 확인용 전문은 루트의 `멘트.md`, 앱 원본은 `karaoke/lyrics-source.md` 이다.

## 3. 앱 반영 (구현됨)
- **데이터:** `songs.js` 의 곡마다 `scene` · `ment`(노래 전) · `closing`(노래 뒤, 마지막 곡만). 가사 `blocks` 에 섞지 않는다. 블록 줄 수는 프롬프터 싱크와 1:1 이기 때문이다.
- **암기 화면:**
  - 곡 맨 위에 장면 이름이 나온다.
  - 그 아래 「🎤 멘트 · 약 N초」 카드, 마지막 곡 끝에는 「🎤 마무리 멘트」 카드가 있다.
  - 가리기(블록가림·첫글자)와 암기 체크는 가사와 똑같이 쓴다. 진행률은 「0/7 블록 · 멘트 1/2」처럼 따로 센다.
  - 「멘트 보이기/숨기기」 설정은 저장된다.
  - **폰에서 수정:** 멘트 카드의 ✏️ → 편집(입력하는 동안 예상 시간 표시) → 저장. 고친 멘트는 그 기기에만 저장되고(localStorage `karaoke.ment.<곡>.<ment|closing>`), 카드에 「수정됨」이 붙는다. 「기본 멘트로」를 누르면 원래 멘트로 돌아간다.
- **2열(태블릿·노트북):** 다단(columns) 배치를 쓴다. 왼쪽 열을 위에서 아래로 다 읽은 뒤 오른쪽 열로 넘어간다. 멘트 카드는 두 열을 가로지른다.
- **프롬프터:** 숨겨 둔 상태 그대로다. `ment` 는 쓰지 않는다.
